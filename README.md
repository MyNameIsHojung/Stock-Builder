# 🏗️ Stock Builder — 주식 공사장

종목을 등록하면 등락률에 따라 꼬마 일꾼들이 건물을 **짓거나(상승)** **부숴요(하락)**.

## 실행

```bash
pnpm start      # 서버 시작 + 브라우저 열기 (http://localhost:4545)
pnpm stop       # 종료
pnpm restart    # 재시작
```

`./start.sh`, `./stop.sh` 를 직접 실행해도 같아요.

- 포트 바꾸기: `PORT=5000 ./start.sh`
- 브라우저 자동 열기 끄기: `NO_OPEN=1 ./start.sh`
- 로그: `logs/server.log`

Node 18 이상만 있으면 되고, 설치할 패키지는 없어요.

## 사용법

| 기능 | 방법 |
|---|---|
| 종목 추가 | 상단 입력창에 종목명(`삼성전자`)·코드(`005930`)·티커(`AAPL`)를 넣고 엔터. 한글은 자동완성으로 고를 수 있어요 |
| 상세 보기 | 카드 클릭 → 팝업 (시세, 1년까지의 차트, 단계 설명) |
| 별명 / 기준가 | 팝업 상단 이름칸 · 하단 기준가 입력 후 **저장** |
| 삭제 | 팝업의 **삭제** 버튼 |
| 순서 바꾸기 | 카드를 끌어서 다른 카드의 왼쪽/오른쪽 절반에 놓기, 또는 팝업의 `◀ 앞으로` / `뒤로 ▶` (터치 화면용) |
| 대시보드 이름 | 좌측 상단 제목 클릭 후 수정 → 엔터 |
| 등락 기준 (종목별) | 팝업의 `기준가 대비` (등록 시점 가격 또는 직접 입력한 매수가) / `전일 대비`. 카드 배지에 `기준가`·`전일`로 표시. 새 종목의 기본값은 ⚙ 설정 |
| 단계·새로고침 주기 | ⚙ 설정 |

화면 그리드는 등록 개수와 창 크기에 맞춰 자동으로 바뀌어요.

## 등락 단계 (기본 10 / 20 / 30%)

| 등락률 | 단계 | 연출 |
|---|---|---|
| +30% ↑ | 🎉 폭풍 건설 | 크레인, 환호하는 일꾼, 폭죽 |
| +20~30% | 🔨 열심히 건설 | 크레인, 빠른 망치질 |
| +10~20% | 🧱 건설 중 | 벽돌 나르기 |
| 0~+10% | 🚶 느긋한 공사 | 천천히 한 층씩 |
| 0% | ☕ 쉬는 중 | 커피 타임 |
| 0~-10% | 🪓 조금 부수기 | 망치로 벽 깨기 |
| -10~-20% | 🚜 철거 중 | 굴삭기, 금 가는 벽 |
| -20~-30% | 💥 대규모 철거 | 먼지 구름, 당황한 일꾼 |
| -30% ↓ | 🧨 폭파! | 폭발, 잔해만 남음 |

건물 층수는 0%일 때 6층이고, ±30%(세 번째 경계값)마다 6층씩 늘거나 줄어요 (0~14층).

## 데이터 (`data/stocks.json`)

```json
{
  "settings": { "title": "우리 동네 주식 공사장", "refreshSec": 60, "tiers": [10, 20, 30], "basis": "base" },
  "stocks": [
    { "id": "…", "symbol": "005930.KS", "name": "삼성전자", "alias": "", "basePrice": 272000, "basis": "base", "addedAt": "…" }
  ]
}
```

서버가 꺼져 있을 때 직접 고쳐도 돼요. `basis`는 `base`(기준가 대비) 또는 `daily`(전일 대비)예요.
종목의 `basis`가 등락 기준이고, 없으면 `settings.basis`(새 종목 기본값)를 따라요.

## 시세 출처

- 가격·차트: Yahoo Finance chart API (지연 시세일 수 있음)
- 국내 종목 한글명·시장 구분·한글 검색: 네이버 증권

## 이미지 (Codex)

`public/assets/*.png` 는 Codex CLI 이미지 생성으로 만들었어요. 원본 고해상도 파일은 `assets_src/`에 있어요.

```bash
pnpm assets              # 없는 이미지만 생성
./scripts/genAssets.sh --force   # 전부 다시 생성
```

## 구조

```
server.js            정적 파일 + REST API + 시세 프록시 (의존성 없음)
public/index.html    화면
public/style.css
public/js/app.js     그리드, 추가/삭제, 팝업, 설정
public/js/scene.js   공사장 애니메이션 엔진 (Canvas)
public/js/assets.js  스프라이트 로더 (빈 여백 자르기)
scripts/genAssets.sh Codex 이미지 생성
start.sh / stop.sh   실행·종료
```
